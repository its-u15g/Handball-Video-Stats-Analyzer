## 📖 かんたん使い方ガイド

### 1. 準備（動画とチーム設定）
1. YouTubeの試合動画URLを上の入力欄に貼り付け、「読込」を押します（限定公開動画やスマホでコピーしたURLにも対応しています）。
2. 右上の「⚙️ 設定」を開き、チーム名を入力します。
   - 選手一覧は「背番号 選手名」の形式（例: `1 田中`）でメモ帳等からコピペして一括登録できます。

### 2. 試合の記録手順
1. **選手を選ぶ**: コート上の背番号、またはGKをタップ（未選択のままだと「チーム全体の記録」になります）。
2. **エリアを選ぶ**: シュートを打った位置（6m中央、9m左、速攻など）をタップ。
3. **結果を押す**: 「ゴール」「GKセーブ」「枠外」「ポスト」のいずれかを押すと自動で記録されます。
4. **ミス・反則**: パスミスやチャージング、2分退場などは右側のボタンを押すだけで即時カウントされます。

### 3. 分析・保存
- **📊 成績・集計**: シュート決定率（SH%）、ターンオーバー率（TO%）、GK阻止率、オフェンス効率（OE）が自動集計されます。
- **📥 CSV出力**: Excelですぐに開ける形式（文字化け防止対応）でダウンロードできます。
- **💾 保存 / 📂 復元**: 試合ごとの分析データをファイルとして保存し、後からいつでも再開できます。# Handball-Video-Stats-Analyzer
